# Cyber Aim

Многопользовательский Aim Trainer на чистом JavaScript (без фреймворков) с мгновенной синхронизацией по WebSockets.

## Особенности
- Соревнование на реакцию в реальном времени.
- Ручной запуск раунда (кнопка в лобби).
- Контроль конкурентного доступа: при одновременном клике по мишени сервер определяет первенство по таймштампу (LWW).
- Офлайн-режим: при обрыве сети выстрелы сохраняются в LocalStorage и синхронизируются при переподключении.
- Логика дисконнекта: при отключении одного из игроков во время раунда игра ставится на паузу и включается 15-секундный таймер ожидания:
  - Если игрок вернулся — игра продолжается.
  - Если не вернулся и остался 1 соперник — оставшемуся присуждается техническая победа.
  - Если играли трое и более — отключившийся исключается, его счет замораживается, а раунд продолжается.
- Сохранение рекордов между запусками в JSON-файле на сервере.

## Запуск
```powershell
npm install
npm start
```
Адрес: http://localhost:3000
