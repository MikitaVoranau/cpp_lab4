# Лабораторная работа №4: Сетевой Aim Trainer (Aim Lab) в реальном времени

> **Cyber Aim** — сетевой соревновательный тренажер реакции и аима (аналог Aim Lab) на чистом JavaScript (без фреймворков) с мгновенной синхронизацией по WebSockets, разрешением конкурентных конфликтов и поддержкой офлайн-режима.

---

## 🎯 Суть игры
- Игроки подключаются к общей соревновательной арене в реальном времени.
- На арене синхронно для всех участников появляются исчезающие мишени разных типов:
  - **Стандартная (бирюзовая):** +10 очков
  - **Бонусная (золотая, быстрее исчезает):** +25 очков
  - **Золотой снайпер (маленькая):** +40 очков
  - **Ловушка-бомба (красная):** -20 очков
- Раунды по 45 секунд. Побеждает игрок, набравший больше всего очков с лучшей точностью.
- Лазерные прицелы других игроков видны в реальном времени с их никнеймами.
- Процедурный синтез звуков выстрелов и попаданий на Web Audio API.

---

## 📋 Выполнение требований задания

### 1. Мгновенная синхронизация через WebSockets:
- Спавн, таймеры и исчезновение мишеней синхронизированы сервером.
- Движение прицелов всех участников передается в реальном времени.
- Таблица лидеров раунда (Live Scoreboard) и чат обновляются мгновенно.

### 2. Только JavaScript, без фреймворков:
- **Клиент:** нативный HTML5 Canvas + Web Audio API + нативный DOM/CSS (Vanilla JS, никаких React, Vue, jQuery).
- **Сервер:** чистый Node.js (`http.createServer` + модуль `ws`). Никаких Express, NestJS и других фреймворков.

### 3. Сохранение данных между запусками (Persistence):
- Сервер автоматически сохраняет рекорды всех времен (Зал славы / Hall of Fame), историю матчей и лог коллизий в файл `server/data/aim_gamestate.json`.
- При перезапуске сервера топ рекордов мгновенно восстанавливается.

### 4. Конкурентный доступ и разрешение конфликтов (на 8–10 баллов):
- Мишени на экране **общие для всех игроков**! Когда два стрелка кликают в одну и ту же мишень почти одновременно (с разницей в доли секунды):
  - Сервер проверяет таймштампы и факт попадания.
  - Фиксируется конфликт: `deltaMs = t2 - t1`.
  - Применяется политика **Last-Write-Wins / First-Come-First-Served**: очки отдаются более быстрому игроку, а на месте цели отображается вспышка «⚡ КОНФЛИКТ / ВАС ОПЕРЕДИЛИ НА N мс».
  - В панели **«Разрешение конфликтов»** в реальном времени появляется запись с именами участников и решением сервера.

### 5. Потеря интернет-соединения и восстановление (на 8–10 баллов):
- Авто-отслеживание событий потери связи (`offline`) и восстановления (`online`).
- Кнопка **«📶 Офлайн режим: ВЫКЛ/ВКЛ»** в шапке для демонстрации преподавателю.
- При потере сети выстрелы и действия игрока сохраняются в локальную очередь (`localStorage`).
- При восстановлении связи очередь действий автоматически отправляется на сервер (`sync_offline_shots`), сервер рассчитывает попадания/конфликты и обновляет статистику.

### 6. Деплой:
- Конфигурационный файл `render.yaml` и поддержка `process.env.PORT` готовы для развертывания на Render.com или Glitch.

## 🚀 Локальный запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер:
   ```bash
   npm start
   ```

3. Откройте в браузере:
   ```
   http://localhost:3000
   ```
   *(Для проверки мультиплеера откройте приложение в двух соседних вкладках браузера).*
